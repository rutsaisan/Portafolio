Descripción del Proyecto

SwellTracker Global es una aplicación web integral diseñada para amantes del surf. Permite consultar las condiciones del mar en tiempo real, acceder a guías de equipamiento, aprender nuevas técnicas a través de tutoriales e incluso disfrutar de un minijuego tematizado.

La plataforma se divide en cuatro secciones principales:

  • 🌊 Olas Condiciones Reales: Tracker de mareas y oleajes por spots en olas.php.
  • 🏄 Equipamiento Guías de Material: Recomendaciones y tipos de tablas en equipamiento.php.
  • 📘 Tutoriales Aprende a Surfear: Lecciones y técnicas de surf detalladas en tutoriales.php.
  • 🎮 Juego Minijuego: Entretenimiento interactivo de surf en Juego.php.

🚀 Funcionalidades Clave

  • Dashboard Interactivo: Collage dinámico en la página de inicio que rota imágenes asíncronamente.
  • Información en Tiempo Real: Seguimiento de spots de surf y condiciones del mar a través de APIs.
  • Sistema de Autenticación: Inicio de sesión seguro y registro de usuarios.
  • Diseño Responsive: Interfaz adaptativa construida con Tailwind CSS y paleta de colores inmersiva.

🛠️ Stack Tecnológico

Desarrollo enfocado en rendimiento y diseño moderno:

PHP (Backend) MySQL Tailwind CSS JavaScript Fetch API

Arquitectura: Aplicación web multipágina con componentes compartidos (navbars, auth) en la carpeta includes.
