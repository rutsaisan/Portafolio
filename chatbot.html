OLLAMA CHAT HUB

Interfaz Minimalista para Modelos LLM Locales

Privacidad y Potencia Local

Comunicación directa con Qwen 2.5 sin salir de tu servidor.

Descripción del Proyecto

Este proyecto es una interfaz de chat ligera desarrollada en PHP que se conecta con la API de Ollama. Permite interactuar con modelos de lenguaje avanzados (como Qwen2.5-Coder) de forma privada y local, eliminando la dependencia de servicios externos.

  • 🤖 Ollama Motor de IA: Orquestación local del modelo qwen2.5-coder:7b.
  • 🐘 PHP Session Memoria de Hilo: Gestión de historial de conversación mediante sesiones nativas.

🚀 Capacidades Técnicas

  • Prompt Engineering: Inyección de reglas para respuestas concisas.
  • cURL Integration: Comunicación asíncrona con el backend de Ollama.
  • Scroll Automático: UX fluida mediante JavaScript para mantener el foco.
  • Clean UI: Diseño inspirado en sistemas de mensajería modernos.

🛠️ Stack Tecnológico

PHP 8.x Ollama API CSS Variables JavaScript (ES6) cURL

Foco: Rendimiento y simplicidad. Sin frameworks pesados, solo código core.

Lógica del Servidor

// Configuración de la petición a la IA
$data = [
  "model" => "qwen2.5-coder:7b",
  "prompt" => $mensaje . ". Resume tu respuesta...",
  "stream" => false
];

// Procesamiento mediante cURL hacia localhost:11434
