Descripción del programa

Este proyecto es un programa en Python que combina entrada de datos, conversión y validación de tipos, condicionales, funciones y bucles para simular un duelo mágico entre un mago y su propio escudo protector. Primero, el usuario introduce la edad del mago. El programa valida la entrada y, si no es un número válido, asigna automáticamente la edad 100.

Magos.py 

# pedir edad
edad_mago = input("Introduce la edad del mago: ")

# convertir a entero
try:
    edad_mago = int(edad_mago)
except: 
    # si falla, pon 100
    edad_mago = 100

# clasifica por edad
if edad_mago < 30: 
    classificacion_mago = "Aprendiz"
    print("El mago es: ", classificacion_mago)
elif edad_mago >= 30 and edad_mago <= 99:
    classificacion_mago = "Hechicero"
    print("El mago es: ", classificacion_mago)
elif edad_mago >= 100:
    classificacion_mago = "Archimago"
    print("El mago es: ", classificacion_mago)

# funcion poderBase
def poderBase(edad):
    if classificacion_mago == "Aprendiz":
        return 10
    elif classificacion_mago == "Hechicero":
        return 15
    elif classificacion_mago == "Archimago":
        return 20

poder = poderBase(edad_mago)
escudo = 15

# empezamos bucle de combate
for turno in range(1, 3):
    if turno == 1:
        print("Turno 1 --> Hechizo de Fuego")
        daño = poder // 2
    else:
        print("Turno 2 --> Hechizo de Rayo")
        daño = poder // 3
    
    # Validaciones
    assert isinstance(daño, int) and daño >= 0, "Error en daño"
    
    escudo = escudo - daño
    print(f"El escudo ha recibido {daño} daño")

    if escudo < 0:
        escudo = 0

    if escudo == 0:
        print("🏆 WINNER! Mago rompe escudo 🏆")
        break
    else:
        print(f"El escudo resiste. Energía: {escudo}")
