Descripción del Proyecto

Beat Blueprint nace de la necesidad de digitalizar el caos creativo en la danza urbana. Es una plataforma diseñada para coreógrafos y directores que permite planificar, enseñar y archivar material artístico en un solo lugar.

El sistema se basa en cuatro pilares fundamentales para el montaje de un show:

  • 🎨 Canvas Escenario Virtual: Diseño de formaciones tácticas en posiciones.php.
  • 📘 Wiki Diccionario de Pasos: Base de datos técnica categorizada en wiki.php.
  • 🎵 Música Gestor de Audio: Control de pistas y playlists en musica.php.
  • 🎬 Vidioteca Repositorio Visual: Archivo de ensayos y referencias en vidioteca.php.

🚀 Funcionalidades Clave

  • Dashboard Dinámico: Acceso rápido a todos los módulos post-autenticación.
  • Subida Asíncrona: Uso de Fetch API para cargar música y vídeos sin recargar la página.
  • Seguridad: Sistema de registro con validaciones de longitud y cifrado.
  • Estandarización: Base de datos para unificar el vocabulario técnico de la academia.

🛠️ Stack Tecnológico

Desarrollo robusto con tecnologías web tradicionales:

PHP (Backend) MySQL Tailwind CSS JavaScript HTML5 Canvas

Arquitectura: Separación clara entre lógica de negocios (php/) y componentes (includes/).

Estructura del Repositorio

  ├── 📁 database/       # Esquema y scripts de base de datos MySQL (db.sql)

  ├── 📄 register.html       # Interfaz de creación de cuenta
  ├── 📄 feed.php       # Centro de control y dashboard del usuario

  ├── 📄 wiki.php       # Wiki Pasos: Base de datos técnica de baile
  ├── 📄 musica.php       # Gestor de pistas de audio y ensayos
  ├── 📄 vidioteca.php       # Biblioteca de referencias visuales
  └── 📄 README.md       # Documentación técnica del proyecto
