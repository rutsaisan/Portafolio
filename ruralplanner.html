Descripción del Proyecto

Rural Planner es una herramienta Full Stack diseñada para solventar los problemas típicos al organizar una salida grupal. Centraliza la toma de decisiones sobre el alojamiento, los gastos de comida y la logística de transporte.

El sistema automatiza el cálculo de costes "a escote", basándose en cuatro módulos integrados:

  • 🏡 Casas Ranking de Alojamiento: Votaciones en tiempo real para elegir la mejor opción.
  • 🛒 Despensa Lista de la Compra: Gestión de productos y responsables de pago.
  • 🚗 Logística Calculadora de Transporte: Estimación de gastos por combustible, peajes o billetes.
  • 🏹 Actividades Planes y Ocio: Propuestas de ocio con control de presupuesto personal.

🚀 Funcionalidades Clave

  • Cálculo Automático: Divide el gasto total entre los asistentes registrados instantáneamente.
  • Panel Admin: Control absoluto de usuarios, borrado de propuestas y moderación.
  • Exportación PDF: Generación de informes (compactos o detallados) para compartir por WhatsApp.
  • Calendario de Disponibilidad: Mapa visual de fechas para encontrar el fin de semana perfecto.

🛠️ Stack Tecnológico

PHP 8.x MySQL (PDO) JavaScript (ES6) Tailwind & CSS Custom Props Local Storage

Arquitectura: Modelo Vista-Controlador (MVC) simplificado con gestión de sesiones segura.
