Historia del Proyecto

En "La Secta Roja", tomas el papel de una heroína que debe enfrentarse a una organización arcana que intenta sacrificar la luz del mundo. Este es un juego de acción tipo bullet-hell desarrollado íntegramente en JavaScript usando la API de Canvas. Implementa lógica de partículas para explosiones, clases orientadas a objetos para los personajes y un sistema de oleadas que culmina en el enfrentamiento con el Sectario Supremo.

Lógica y Funcionamiento

El juego se apoya en cuatro pilares fundamentales de programación que garantizan una experiencia fluida y reactiva:

Bucle Principal (Game Loop)

Utiliza requestAnimationFrame para sincronizar el dibujo con la tasa de refresco del monitor, logrando 60 FPS estables. En cada frame se limpia el lienzo, se calculan nuevas posiciones y se renderizan los objetos.

Arquitectura POO

Emplea Clases (Jugador, Npc, Boss) para encapsular propiedades como salud, velocidad y comportamiento. Esto permite heredar funcionalidades comunes y personalizar ataques específicos para el jefe final.

Detección de Colisiones

La lógica básica de impacto utiliza comparación de coordenadas rectangulares (Bounding Box). Si un proyectil entra en el área ocupada por una entidad, se reduce su salud y se activa el sistema de efectos.

Sistema de Partículas

Para las explosiones, se generan ráfagas de objetos de la clase Particula con trayectorias aleatorias y un factor de "vida" decreciente que controla su opacidad hasta desaparecer.
