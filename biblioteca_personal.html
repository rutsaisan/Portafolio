Descripción del proyecto

Este sistema de gestión nació para solucionar el caos de las colecciones físicas. Desarrollado con PHP y MySQL, permite a los usuarios centralizar su biblioteca, organizando no solo los datos técnicos, sino también la experiencia personal de lectura.

El corazón del proyecto es su seguimiento de estado dinámico, que adapta los campos del formulario según la situación del libro:

  • 🟡 Deseado Libros pendientes de compra, incluyendo control de precios.
  • 🔵 Leyendo Progreso actual marcando el capítulo por el que vas.
  • 🟣 Leído Archivo histórico con valoración personal de 1 a 5 estrellas.

✨ Funcionalidades Clave

  • CRUD Completo: Gestión total de libros, autores y categorías en la base de datos.
  • Sistema de Portadas: Carga y almacenamiento de imágenes en servidor local.
  • Feed Interactivo: Tarjetas visuales que cambian de color según el estado del libro.
  • Seguridad: Autenticación de usuarios con login y registro cifrado.

💻 Tecnologías

Stack robusto para una aplicación web tradicional:

PHP 7.4+ MySQL (MySQLi) Tailwind CSS JavaScript Google Fonts (Inter/Quicksand)

Bonus: Incluye un sistema de auto-migración que actualiza la estructura SQL automáticamente.
