Descripción del proyecto

Esta página surgió de una necesidad real: tenía que dar una charla en los Scouts sobre relaciones afectivas para aprender a identificar qué queremos, qué personas nos suman y cuáles no.

Vibe Check: El Semáforo de las Relaciones es una aplicación web interactiva diseñada bajo el formato de "presentación guiada". Su propósito es enseñar a identificar la calidad de los vínculos utilizando una metáfora universal:

  • 🔴 Red Flags: Peligro (violencia, control).
  • 🟡 Yellow Flags: Precaución (ambigüedad).
  • 🟢 Green Flags: Relación sana (seguridad).

El proyecto combina psicoeducación con gamificación para hacer el aprendizaje ligero y memorable, evitando que se sienta como una "lección aburrida".

✨ Funcionalidades Clave

  • Minijuego "Flag Sorter": Lógica en JavaScript puro que presenta situaciones aleatorias y evalúa la decisión del usuario con feedback instantáneo.
  • Narrativa Visual: Diseño de fondos y assets que transicionan suavemente entre estados de ánimo (del caos rojo a la paz verde).
  • Micro-interacciones: Animaciones CSS (blob, fade-in, shake para errores) que hacen la experiencia táctil y reactiva.

💻 Tecnologías

Construido con un enfoque moderno y ligero:

HTML5 Semántico Tailwind CSS Vanilla JavaScript Arte generado por IA

El diseño es responsive (adaptable a móviles) y sigue la metodología "Utility-First" para los estilos.

🎨 Enfoque de Diseño

Este proyecto rechaza la estética clínica habitual de la salud mental para abrazar un estilo "Cozy UI" (amigable y acogedor). A través de una paleta de colores semántica y un diseño centrado en la narrativa, los usuarios navegan por los matices de las relaciones humanas sin sentirse juzgados.
